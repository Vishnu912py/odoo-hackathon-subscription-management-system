# plan.md

## Goal

Build a robust subscription management system on Odoo with clear workflows and maintainable structure.

## Milestones

1. **Foundation**
   - Define scope and user roles.
   - Establish module structure and coding conventions.
2. **Core subscription flows**
   - Implement plan creation and subscription lifecycle handling.
   - Support activation, renewal, upgrade/downgrade, and cancellation flows.
3. **Billing and reporting**
   - Integrate billing-related workflow support.
   - Provide essential operational reporting views.
4. **Hardening**
   - Add automated tests for critical flows.
   - Improve validation, error handling, and documentation.

## Near-term priorities

- Finalize data model for subscriptions, plans, and customer linkage.
- Implement minimal end-to-end happy path for subscription lifecycle.
- Add tests for lifecycle state transitions.
